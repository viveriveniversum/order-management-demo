# Order Management Demo

Welkom bij de Order Management Demo! Dit project bevat een fullstack applicatie met een Angular frontend en een Express.js backend.

## Assessment
Voor meer details over de opdracht en de vereisten, bekijk de [assessment.md](./assessment.md).

## Projectstructuur
```
/client  → Angular frontend
/server  → Express backend
```

## Installatie en starten
1. Clone deze repository:
   ```bash
   git clone https://github.com/jouw-gebruikersnaam/order-management-demo.git
   cd order-management-demo
   ```

2. Installeer de dependencies voor zowel de frontend als de backend:
   ```bash
   cd client
   npm install
   cd ../server
   npm install
   ```

3. Start de backend:
   ```bash
   cd server
   npm start
   ```

4. Start de frontend:
   ```bash
   cd client
   npm start
   ```

5. Open de applicatie in je browser op [http://localhost:4200](http://localhost:4200).

## Technische keuzes
- **Frontend:** Angular met AG-Grid voor datavisualisatie.
- **Backend:** Express.js voor API-functionaliteit.
- **Mono-repository:** Voor eenvoud in beheer en samenwerking.
